# 月相查詢 Moon Phase Checker

A single-page moon phase checker (Traditional Chinese UI). It works from the visitor's current date, time, and time zone, and uses Meeus astronomical formulas.

Open `index.html` locally, or see the live site: https://moon-phase-psi.vercel.app

Pushing to `main` triggers an automatic Vercel deployment (project `moon-phase`, team `puppy0831`).
