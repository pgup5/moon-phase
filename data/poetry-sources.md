# Daily moon poetry

The daily collection contains 366 distinct classical Chinese excerpts, with author and title. It retains the original 17 excerpts and adds 349 excerpts from the Traditional Chinese Tang poetry JSON files in [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry).

Upstream revision: `b8594f81a89752241442f2ce267d6f66f96704ee`. Each imported entry stores its source JSON filename. Source files are under [全唐诗](https://github.com/chinese-poetry/chinese-poetry/tree/b8594f81a89752241442f2ce267d6f66f96704ee/全唐诗). The upstream MIT license is preserved in [chinese-poetry-LICENSE.txt](chinese-poetry-LICENSE.txt). Ancient poems are public domain; the transcription follows this dataset, which can contain textual variants. These are excerpts, not complete works.

Selections explicitly reference the Moon or moonlight; calendar-month-only references were excluded. No verses or attributions are AI-generated. English mode retains the original Chinese when an existing translation is unavailable and labels it as original Chinese.

Selection follows the visitor's **local calendar date**, independent of Moon phase, in a 366-day repeating cycle anchored at 2026-01-01. Every consecutive 366 calendar days receives a different excerpt. Leap day is included, and daylight-saving time does not change the index. The page and birthday card use the same selection for a given date.
